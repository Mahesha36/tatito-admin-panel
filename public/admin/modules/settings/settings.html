SMTP Instructions

Please be careful when configuring SMTP. Incorrect settings cause errors during order placement, registrations, or newsletter sending.

For Non-SSL:
  • Use sendmail if SMTP fails
  • Set Mail Port to 587
  • Use TLS encryption
For SSL:
  • Use sendmail if SMTP fails
  • Set Mail Port to 465
  • Use SSL encryption
